# Project Contribution
A healthy community is the backbone of any `open-source` project. Let's keep things simple.

## Criteria / Considerations

* *Branch* - Always raise a pull-request to `develop` branch only. Pull requests to `main` is reserved for maintainers only and any such requests may be cancelled.

* Change for one platform should not break the flows for other platform(s) (android or desktop).

* Always perform a real test on the platform for which the changes are made (android or desktop).
